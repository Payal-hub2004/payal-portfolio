# Payal Portfolio

## Run locally
1. Install Node.js
2. Open this folder in VS Code
3. Run: `npm install`
4. Run: `npm run dev`

## Personalize
- Put your photo at `public/profile.jpg`, then replace the placeholder in `src/App.jsx` with an `<img src="/profile.jpg" ... />`.
- Put your resume at `public/resume.pdf`.
- Replace `YOUR_EMAIL`, `YOUR_LINKEDIN_URL`, and `YOUR_GITHUB_URL`.
- Replace the undergraduate education placeholder only after confirming the exact details.
- Replace `#` project/certificate links with your real URLs.

## Deploy
Push the folder to GitHub, import the repository into Vercel, and deploy as a Vite project.
